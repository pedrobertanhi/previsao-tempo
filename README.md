# Previsão do Tempo

Um simples projeto que mostra a previsão do tempo de uma cidade.

## Como usar

1. Abra o arquivo `index.html` em seu navegador.
2. Digite o nome da cidade que você quer saber a previsão do tempo.
3. Clique no botão de pesquisar.

## Tecnologias Utilizadas

* HTML
* CSS
* JavaScript

## API

* [OpenWeatherMap](https://openweathermap.org/current)
